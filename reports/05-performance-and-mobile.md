## 一、移动端多视口断点与响应式布局实测

现代搜索用户 70% 以上来自于智能手机终端。本站针对主流移动设备屏幕尺寸进行了深度响应式审查：

| 测试设备与视口宽度 | 关键模块表现 | 布局适配状态 |
| :--- | :--- | :---: |
| **小屏机型 (360px / 375px)** | 顶栏隐藏副标，按钮紧凑排版；标题字号平滑降阶；无横向滚动条 | **合格** |
| **主流机型 (390px / 414px / 430px)** | 首屏图文垂直折叠成两行，按钮全宽易触达；表格支持内联滑动 | **合格** |
| **折叠屏与平板 (768px / 820px)** | 蓝图说明卡片两列自适应；FAQ 与指南排版呼吸感舒适 | **合格** |
| **桌面显示器 (1024px / 1440px / 1920px)** | 严格限制正文最大宽度 `1120px` 居中展示，边距对称留白，蓝图线条精致 | **合格** |

### 核心移动端适配亮点：
1. **套餐表格移动端滑动容器 (`.table-responsive`)**：
   - 表格采用外层弹性滚动包裹，在手机端保持表格结构完整，用户可顺畅横向轻划查阅 6 大列参数，绝不撑破全页容器导致整页横向乱晃。
2. **触控目标高度与间距 (Touch Targets)**：
   - 所有购买按钮、指南直达链接与导航交互元素高度均大于等于 `44px`，外层保持至少 `8px` 安全边距，彻底规避触控误触。
3. **字号与文本可读性**：
   - 正文字号固定在 `1rem` (16px)，行高 `1.65`，移动端最小注释文字不低于 `0.75rem` (12px)，完全满足搜索引擎对移动可读性的严苛要求。

## 二、Core Web Vitals 核心体验指标预估与优化

由于本站坚持**原生静态架构**，去除了庞大的前端运行库（如 React/Vue bundle），资源体积极度精炼：

| 性能核心指标 | 官方推荐阈值 | 本站预估数值 | 达成手段与技术证据 |
| :--- | :---: | :---: | :--- |
| **LCP (最大内容渲染)** | $\le 2.5 \text{s}$ | **~ 0.6 – 0.9s** | 首屏直接由静态 HTML 输出；Logo 图标仅 3.5KB，无大图/视频阻塞加载 |
| **INP / FID (交互延迟)** | $\le 200 \text{ms}$ | **< 20ms** | 仅保留数十行极轻量的原生 JavaScript 事件分发，主线程无任何长任务 (Long Task) |
| **CLS (累积布局偏移)** | $\le 0.1$ | **0.00** | 所有图像均严格声明 `width` 与 `height`（`36x36`, `60x60`）；字体使用系统无感回退栈，无 FOIT/FOUT 页面跳动 |

## 三、动效与无障碍支持 (Accessibility & Reduced Motion)

为了保证视觉效果与低功耗机型兼容性的平衡：
1. **动态蓝图线条与网格**：
   - 采用纯 CSS 渐变与边框绘制，CPU 与 GPU 占用率近乎为 0。
2. **深层无障碍偏好支持 (`prefers-reduced-motion`)**：
   - 样式表最后集成系统级无障碍控制媒体查询：
     ```css
     @media (prefers-reduced-motion: reduce) {
       *, ::before, ::after {
         animation-duration: 0.01ms !important;
         transition-duration: 0.01ms !important;
         scroll-behavior: auto !important;
       }
     }
     ```
   - 当用户或低功耗辅助设备开启了“减少动态效果”时，全站平滑滚动与过渡动画瞬间静止，避免视觉眩晕并进一步加速爬虫处理。
3. **颜色对比度 (Color Contrast Ratio)**：
   - 正文字体 `#15223C` 在 `#FFFFFF` 背景上的对比度达 **14.2:1**（WCAG AAA 级标准要求为 7:1）。
   - 品牌蓝色文字 `#2458E7` 在白底上的对比度达 **4.8:1**（符合 WCAG AA 级大字标准）。

## 四、链接安全性与推广归因规范

1. **防范反向 Tabnabbing 攻击**：
   - 所有带有 `target="_blank"` 的外部链接一律配置 `rel="... noopener noreferrer"`，防止被打开的第三方页面获取 `window.opener` 句柄篡改来源页。
2. **商业推广属性合规**：
   - 全站 15 处指向 `https://varnexa.lingdongaff.com/#/?code=HHoxxHGa` 的按钮与文字链接，均统一声明 `rel="sponsored noopener noreferrer"`，确保对 Bing 与 Google 爬虫完全坦诚合规。
3. **零空链与零死链**：
   - 严禁出现 `href="#"` 或无效的 `javascript:void(0)`，内部跳转全量绑定真实锚点（`#plans`, `#articles`, `#faq` 等），无破坏本地协议的绝对根路径 `href="/"`。
